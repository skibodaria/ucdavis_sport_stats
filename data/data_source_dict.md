# Data Sources & Data Dictionary for This Project


## Data Source
The data for this project comes from a course provider -- UCDAVIS -- with a direct link to a [Dropbox folder](https://www.dropbox.com/scl/fo/idnc4sbvj9cmefwl51ruy/AFmpaGLav_ZytNbFRs-Iwcw?rlkey=u3y8qw3hsza4jhg3pnqnwcxct&e=2&dl=0). The folder consists from two files:

* `athlete_events.csv.zip` -- a `.zip` archive which can be unpacked to a flat table with multiple records, represented in `.csv` format; contains information about Olympic Games participations; consists of 271116 rows and 15 columns (see below in the "Data Dictionary" explanations);
* `noc_regions.csv` -- a text file which contains information about local teams and National Olympic Commitees; consists of 230 rows and 3 columns.
